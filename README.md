# Human Activity Recognition using Deep Learning

This project applies a Dense Neural Network to classify human activities (e.g., walking, sitting, standing) based on accelerometer and gyroscope data. The model is trained, tuned, and evaluated using TensorFlow and Keras Tuner.

## Features
- Preprocessing with Min-Max Scaling and Label Encoding
- Dense Neural Network with Dropout regularization
- Hyperparameter tuning using Keras Tuner
- Training/Validation accuracy and loss visualization

## Tech Stack
- Python
- TensorFlow / Keras
- Pandas / NumPy / Matplotlib / Seaborn
- Scikit-learn
- Keras Tuner

## How to Run

```bash
pip install -r requirements.txt
python human_activity_project.py
